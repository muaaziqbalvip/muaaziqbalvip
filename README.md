## What I'm building

| Project | What it is |
| --- | --- |
| [**Asaan Lang**](https://github.com/muaaziqbalvip/asaan-lang) | An experimental programming language and learning tool using Urdu and Roman-Urdu keywords, with a small interpreter and HTML site builder. |
| [**SIRAVEX**](https://github.com/muaaziqbalvip/SIRAVEX) | An installable browser media player for people’s **own authorized** playlists and media sources. |
| [**Mizanora**](https://mizanora.vercel.app) | An online marketplace project, built around a local shopping experience and cash-on-delivery ordering. |
| [**BarakatWave TV**](https://github.com/muaaziqbalvip/BarakatWave-TV) | A streaming-platform experiment exploring playlist and playback tools. Use only content you’re authorized to access or distribute. |
| [**Mizanora AI WhatsApp**](https://github.com/muaaziqbalvip/MIZANORA-AIWHATSAPP) | An integration project exploring conversational AI and messaging APIs. |

> These are independent projects in progress. Features, availability, and integrations can change; please check each project’s own README for current details.
